# Python and object-oriented programming

[← Back to Common Core](../README.md)

This area contains eleven Python Piscine repositories, followed by A-Maze-ing and Pacman. The Piscine exercises retain their original exercise-based layout.

### Python Piscine

| Project | Focus |
| --- | --- |
| [Growing Code](https://github.com/soloinplace/42-Growing_Code) | Python fundamentals, functions, control flow and recursion. |
| [CodeCultivation](https://github.com/soloinplace/42-CodeCultivation) | Classes, methods, encapsulation and inheritance. |
| [Garden Guardian](https://github.com/soloinplace/42-Garden_Guardian) | Exceptions, custom errors and cleanup with finally. |
| [Data Quest](https://github.com/soloinplace/42-Data_Quest) | Lists, tuples, sets, dictionaries, generators and comprehensions. |
| [Data Archivist](https://github.com/soloinplace/42-Data_Archivist) | File I/O, streams and context managers. |
| [Code Nexus](https://github.com/soloinplace/42-Code_Nexus) | Abstract classes, polymorphism and data-processing pipelines. |
| [The Codex](https://github.com/soloinplace/42-The_Codex) | Modules, packages and Python import mechanics. |
| [DataDeck](https://github.com/soloinplace/42-DataDeck) | Object-oriented design with abstract classes, capabilities and battle strategies. |
| [The Matrix](https://github.com/soloinplace/42-The_Matrix) | Python environments, dependencies and configuration through environment variables. |
| [Cosmic Data](https://github.com/soloinplace/42-Cosmic_Data) | Structured data validation with Pydantic models, constraints and validators. |
| [FuncMage](https://github.com/soloinplace/42-FuncMage) | Lambdas, higher-order functions, closures, functools and decorators. |
